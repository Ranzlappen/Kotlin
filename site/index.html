What's inside

🏗️ Modern architecture

app + core + feature modules, MVVM with StateFlow, Hilt DI, pure-Kotlin domain layer with JVM unit tests.

🎨 Design system

Material 3 with dynamic color, dark/light/system themes, spacing tokens, adaptive navigation from phone to tablet.

🌍 Localization first

English and German out of the box, per-app language picker, and lint that fails the build on untranslated strings.

🐛 Feedback built in

Bug reports and feature requests from inside the app — device snapshot, Markdown report, prefilled GitHub issue or email.

🚀 CI/CD ready

Formatting, static analysis, lint, tests, CodeQL and secret scanning, plus a one-click release workflow producing signed APK + AAB.

📜 The Lastenheft twist

A personal requirements spec baked into the repo. AI agents that scaffold from this template must run its final pass — every requirement checked, every gap reported.
